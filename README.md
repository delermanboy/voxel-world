# 体素世界 (Voxel World)

一个类似 Minecraft 的 Web 3D 体素沙盒游戏，使用 Three.js 构建，单文件 HTML，浏览器直接打开即可运行。

## 功能特性

- **无限世界**：Chunk 分块动态加载/卸载，程序化地形生成
- **方块系统**：18 种方块（草、泥土、石头、矿石、木头、树叶、水、玻璃等）
- **像素纹理**：Canvas 生成 16x16 像素风格纹理图集
- **日夜循环**：天空渐变、太阳/月亮、云层漂移
- **物理引擎**：AABB 碰撞、平滑移动、台阶攀爬、摔落伤害
- **生物 AI**：猪、鸡、牛、羊（被动）、僵尸、骷髅（敌对），行走动画
- **合成系统**：16 个配方
- **存档系统**：LocalStorage 自动保存/加载
- **掉落物**：3D 旋转物品实体，自动拾取

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| 空格 | 跳跃/上浮 |
| Shift | 冲刺 |
| 鼠标 | 视角 |
| 左键(按住) | 破坏方块 |
| 右键 | 放置方块 |
| E | 攻击生物/暂停 |
| C | 合成台 |
| Tab | 背包 |
| 1-9 | 切换快捷栏 |
| F3 | 调试信息 |
| ESC | 暂停 |

## 运行方式

直接用浏览器打开 `index.html` 即可（需要联网加载 Three.js）。

或使用本地服务器：
```bash
cd voxel-world
python3 -m http.server 8080
```
访问 `http://localhost:8080`

## 技术栈

- [Three.js](https://threejs.org/) - 3D 渲染引擎
- 纯 HTML/CSS/JavaScript，无构建工具
